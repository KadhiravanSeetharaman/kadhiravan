## UNDERSTANDING THE STREAK

- **Current streak:** Consecutive days with at least one qualifying GitHub contribution, ending today or on the most recent day counted by the streak provider.
- **Longest streak:** The highest number of consecutive days with qualifying contributions recorded in the account's contribution history.
- **Total contributions:** Qualifying contributions counted by the streak provider during the reporting period shown on its card.

<sub>GitHub contribution streaks depend on qualifying activity and the provider's calculation rules. Not every GitHub action necessarily counts as a contribution.</sub>
